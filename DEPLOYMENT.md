# Тестовая публикация GEAR на Render

Проект запускается как обычный Node.js-сервер. Перенос на другой Node-хостинг не требует переписывания интерфейса.

## Настройки Render

- Репозиторий: baarsss/GEAR, ветка main, корень репозитория.
- Тип: Web Service, Node, тариф **Free**.
- Build Command: `npm install --include=dev && npm run build:node`
- Start Command: `npm run start:node`
- Node: `22.22.0`, NODE_ENV: `production`.
- Health Check: `/api/health`.
- Порт задаёт Render через PORT; сервер слушает 0.0.0.0.
- Серверные переменные окружения: `SUPABASE_URL` и `SUPABASE_PUBLISHABLE_KEY` из Supabase → Settings → API Keys. Используйте только publishable key, не secret key.

Эти параметры также записаны в render.yaml для создания через Blueprint.
Не включайте платные ресурсы для тестового запуска.

## Проверка перед публикацией

1. `npm install --include=dev`
2. `npm run build:node`
3. `npm run start:node`
4. Проверить главную, фильтры, карту, /service/1, /service/1000, /privacy, /consent, /api/health, /api/catalog, /account и /provider.

В базе сначала выполните `db/migrations/0001_catalog.sql`, затем `db/migrations/0002_accounts.sql` через Supabase SQL Editor. На тестовом сайте карточка `GEAR Демо БД` подтверждает работу подключения. Исполнитель может отправить карточку через `/provider`; она получает статус `pending` и становится видимой в каталоге только после ручной проверки и смены статуса на `published` в Supabase Studio. Юридические лица дополнительно требуют статуса проверки `verified`. Таблица защищена RLS: публичный API может читать только опубликованные строки, исполнитель — свои заявки, но не может публиковать или редактировать запись.

Для проверки входа в Supabase Auth включите Email и подтверждение e-mail, укажите Site URL `https://gear-demo-e6fw.onrender.com` и разрешённый Redirect URL `https://gear-demo-e6fw.onrender.com/auth/complete`. Встроенный отправитель Supabase ограничен e-mail участников проекта. Не отключайте подтверждение e-mail ради обхода ограничения: для открытого запуска подключите SMTP-провайдера и проверьте доставку.

## Ограничения демоверсии

23 исходных объявления и одна запись в Supabase демонстрационные. Тестовый вход по e-mail и роли записываются в Supabase; обращения клиентов, чат, отзывы, загрузка файлов, панель модератора и оплата ещё не реализованы. Не открывайте регистрацию для широкой публики и не используйте сайт для реальных заявок, пока не утверждены окончательные юридические документы с данными оператора, сроки хранения и трансграничная обработка, а также не подключена почта для пользователей.
Индексация отключена через robots metadata (это не ограничение доступа).
Бесплатный сервер может засыпать; первый запрос после простоя будет медленнее.
Не храните пользовательские файлы на локальном диске бесплатного сервера.

Для полноценного запуска понадобятся хранилище файлов, почтовый провайдер,
резервные копии, окончательные юридические документы и проверка безопасности.
Перед публичным рабочим запуском пересмотрите robots metadata в app/layout.tsx.
