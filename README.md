# GEAR — каталог автоуслуг

Независимый тестовый сайт для поиска автоуслуг в Беларуси. Интерфейс работает на Vinext/React, сервер запускается на Node.js. Новые опубликованные объявления читаются из Supabase PostgreSQL через Data API; 23 исходные демонстрационные карточки пока остаются в коде и отмечаются «Демо».

## Запуск локально

- Node.js >= 22.13
- `npm install --include=dev`
- `npm run dev` — локальная разработка
- `npm run build:node` и `npm run start:node` — проверка сборки для Render

Без переменных Supabase сайт продолжает показывать только демонстрационные карточки. Для подключения каталога задайте в окружении сервера:

```text
SUPABASE_URL=https://<project-ref>.supabase.co
SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
```

Не используйте секретный `sb_secret_...` или `service_role`: сайт читает каталог с публичным ключом и опирается на RLS. В репозиторий не добавляйте `.env` и настоящие учётные данные.

SQL-схема: сначала выполните [`db/migrations/0001_catalog.sql`](db/migrations/0001_catalog.sql), затем [`db/migrations/0002_accounts.sql`](db/migrations/0002_accounts.sql) в SQL Editor проекта Supabase. Первая миграция создаёт каталог и одну вымышленную тестовую карточку. Вторая добавляет профили пользователей, роли и заявки исполнителей. RLS разрешает посетителю читать только опубликованные объявления; исполнитель видит также свои заявки. Публикует объявление после проверки только администратор через Supabase Studio. Для юридического лица перед публикацией требуется `verification_status = 'verified'` после проверки документов; загрузка документов в интерфейсе пока не реализована.

`GET /api/catalog` возвращает опубликованные записи. Каталог, фильтры, карта и страница `/service/<id>` используют их без пересборки сайта. Для ограниченного теста есть вход по ссылке на e-mail, выбор роли, кабинет исполнителя и отправка объявления на модерацию. Телефон при регистрации не нужен; контактный телефон запрашивается только в объявлении. В Supabase Auth включите Email, подтверждение e-mail и redirect URL `https://gear-demo-e6fw.onrender.com/auth/complete`. Встроенная почта Supabase отправляет письма только участникам проекта; для открытой регистрации нужен собственный SMTP-провайдер. Чат, отзывы, загрузка файлов, панель модератора и оплата пока не реализованы. Перед рабочим запуском необходимы окончательные юридические документы с данными оператора, настройка почты, резервное копирование и проверка безопасности.

Настройки развёртывания — в [`DEPLOYMENT.md`](DEPLOYMENT.md).
